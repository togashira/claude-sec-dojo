# よくある質問 (FAQ)

**Q. このリポジトリで攻撃手法(侵入テストなど)は学べますか?**
学べません。本リポジトリは意図的に「防御・検知・報告」の実務力に範囲を絞っています。攻撃手法を学びたい場合は、正規の認可を得たCTFやラボ環境を提供する教材(他のOSS・専門講座など)を探してください。

**Q. 実際のログや設定ファイルをClaudeに入力してもいいですか?**
推奨しません。実際の社内ログ・認証情報・顧客データには個人情報や機密情報が含まれる可能性があります。本リポジトリのハンズオンはダミーデータでの学習を想定しています。実データを扱う場合は、必ず会社のセキュリティ方針・データ取り扱いルールに従い、匿名化・サンプリングなどの対策をしてください。

**Q. Claudeの指摘(「これは怪しい」「これはリスクがある」)はそのまま信じていいですか?**
出発点として扱ってください。Claudeは可能性のある異常やリスクを洗い出すのが得意ですが、誤検知(false positive)も起こります。最終的な判断・対応は、現場の状況を知る人間が行ってください。

**Q. プログラミングができないのですが、tools/ 以下は使えますか?**
`tools/` 以下はPythonの基礎知識が必要です。まずは `modules/` と `templates/` をチャット([claude.ai](https://claude.ai))で使うところから始めてください。

**Q. セキュリティ専門チームがいる会社でも意味がありますか?**
はい。本リポジトリは専門チームの代わりになるものではなく、現場のインフラ・クラウドエンジニアが「一次対応・一次レビュー」の質を上げるためのものです。専門チームへのエスカレーション判断を早く・正確にするのにも役立ちます。
