# よくある質問 (FAQ)

**Q. 無料で使えますか?**
[claude.ai](https://claude.ai) には無料プランがあり、まずはそこから試せます。利用量が増えたら有料プランやAPI利用を検討してください。

**Q. 社外に出せない情報を入力しても大丈夫ですか?**
Anthropicの利用規約・プライバシーポリシーを確認し、社内のセキュリティ方針に従ってください。機密情報(個人情報、未公開の財務情報など)を入力する際は、匿名化・抽象化するなど注意してください。本リポジトリのテンプレートも、実データではなくダミーの値で試すことを推奨します。

**Q. Claudeの回答はそのまま使っていいですか?**
下書き・たたき台として使い、必ず人間が内容を確認・修正してから使用してください。特に対外的な発信、法務・財務・人事に関わる内容は要注意です。

**Q. プログラミングができないのですが、tools/ 以下は使えますか?**
`tools/` 以下はPythonの基礎知識が必要です。まずは `templates/` のプロンプトをチャット([claude.ai](https://claude.ai))で使うところから始めてください。ツールを使いたい場合は、社内のエンジニアに相談するのがおすすめです。

**Q. どのプランやモデルを選べばいいですか?**
用途によって異なります。日常的な文章整理や要約であれば標準的なプランで十分なことが多いです。詳しくは[Anthropic公式サイト](https://www.anthropic.com)の料金ページを確認してください。本リポジトリは特定のプランを推奨するものではありません。
