# ユースケース集

経営・マネジメント業務でClaudeをどう使えるか、場面別に紹介します。対応するプロンプトテンプレートがある場合はリンクしています。

## 意思決定

- 複数の選択肢の長所・短所を整理してもらう → [decision-support-prompt.md](../../templates/ja/decision-support-prompt.md)
- 意思決定の前提となるリスクを洗い出してもらう
- 過去の似た判断との比較を整理してもらう

## 会議・コミュニケーション

- 会議メモから議事録・決定事項・ToDoを抽出する → [meeting-minutes-prompt.md](../../templates/ja/meeting-minutes-prompt.md)
- 社内向けの連絡文・お知らせの文面を下書きする
- 難しい伝達事項を、相手に合わせて言い換える

## レポーティング

- 週次・月次の活動を箇条書きから報告書形式に整える → [weekly-report-prompt.md](../../templates/ja/weekly-report-prompt.md)
- 複数部署からの報告を1つのサマリーにまとめる

## 戦略・振り返り

- OKR・KPIの進捗を振り返り、次アクションを考える → [okr-review-prompt.md](../../templates/ja/okr-review-prompt.md)
- 競合情報や市場動向のメモを整理する
- 事業計画書のドラフトにフィードバックをもらう

## 自動化(ツールが必要)

- 毎週決まった形式のレポートを自動生成する → [tools/weekly-report-agent/](../../tools/weekly-report-agent/)
