# はじめに

## Claudeとは何か

Claudeは、Anthropic社が開発したAI(大規模言語モデル)です。文章を読んで理解し、文章で答えるのが得意で、以下のような経営・マネジメント業務に活用できます。

- 会議の議事録・メモから要点を抽出する
- レポートや報告書の下書きを作る
- 複数の選択肢を整理して意思決定を助ける
- メール・社内文書の文面を考える・直す
- 契約書・企画書を要約する、リスクを洗い出す

**重要な前提:** Claudeは便利な「下書き・整理」のパートナーですが、最終判断は人間(あなた)が行うものです。特に法務・財務・人事に関わる内容は、必ず人間が確認してください。

## 使い方は2種類ある

### 1. チャットで使う(プログラミング不要)

[claude.ai](https://claude.ai) にアクセスしてアカウントを作れば、すぐにチャット形式でClaudeに質問・依頼ができます。[templates/ja/](../../templates/ja/) にあるプロンプトをコピーして貼り付けるだけで使えます。

これが最も簡単な始め方です。**まずはここから始めてください。**

### 2. ツール・自動化として使う(多少の技術知識が必要)

社内システムに組み込んだり、定期的なレポートを自動生成したりしたい場合は、Claude API(開発者向けの仕組み)を使います。本リポジトリの [tools/](../../tools/) にサンプルがあります。

プログラミング未経験の場合は、社内のエンジニアやITチームに相談しながら進めることをおすすめします。

## 最初の一歩

1. [templates/ja/decision-support-prompt.md](../../templates/ja/decision-support-prompt.md) を開く
2. 内容をコピーし、自社の状況に合わせて `[ ]` の部分を書き換える
3. [claude.ai](https://claude.ai) に貼り付けて、結果を確認する

慣れてきたら [use-cases.md](use-cases.md) で他の活用例も見てみてください。
