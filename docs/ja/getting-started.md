# はじめに

## このリポジトリで学べること

ここで学ぶのは「攻撃の方法」ではなく、**ネットワーク・クラウド・サーバーの現場で、セキュリティの観点から状況を理解し、適切に対応する力**です。具体的には:

- ログの中から怪しい挙動を見つけ、優先度をつける
- クラウド(AWS/Azure)の設定を、セキュリティの観点でレビューする
- インシデントが起きたときに、状況を整理して報告する

これらはネットワーク運用・クラウド構築エンジニアであれば、専門のセキュリティチームでなくても日常的に求められる力です。

## Claudeをどう使うか

Claudeは「セキュリティの専門知識を持つ相棒」として、以下のように使えます。

- 長いログを読んで要点をまとめてもらう
- 設定ファイル(IaCや各種コンフィグ)をレビューしてもらい、リスクを指摘してもらう
- インシデント対応の初動で、次に確認すべきことを一緒に整理する

**重要な前提:** Claudeの指摘は出発点であり、最終判断・実際の対応は人間(あなた)が行うものです。特に本番環境に影響する操作は、必ず人間が確認・承認してください。また、本番の機密情報(実際のログ、認証情報、顧客データ)をそのまま入力しないよう注意してください。

## 使い方は2種類ある

### 1. チャットで使う(プログラミング不要)

[claude.ai](https://claude.ai) にアクセスしてアカウントを作れば、すぐにチャット形式でClaudeに質問・依頼ができます。[templates/ja/](../../templates/ja/) にあるプロンプトをコピーして貼り付けるだけで使えます。

**まずはここから始めてください。**

### 2. ツール・自動化として使う(多少の技術知識が必要)

定期的なログレビューを自動化したい場合は、Claude API(開発者向けの仕組み)を使います。本リポジトリの [tools/](../../tools/) にサンプルがあります。

## 最初の一歩

1. [learning-path.md](learning-path.md) を読み、学習の進め方を確認する

3. 慣れてきたら [templates/ja/](../../templates/ja/) のプロンプトを自分の現場のログ・設定(ダミー化したもの)に当てはめて試す
