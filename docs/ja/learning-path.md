# 学習パス

4つのモジュールを、この順番で進めることを推奨します。各モジュールは「ネットワーク運用 → クラウド → ログ分析・インシデント対応 → 設定レビュー」という、現場のインフラ/クラウドエンジニアが経験しやすい流れに沿っています。

| # | モジュール | 学ぶこと |
|---|---|---|
| 1 | [ネットワークログ分析の基礎](../../modules/01-network-log-analysis/README.md) | ネットワーク機器のログから異常を見つける考え方 |
| 2 | [クラウドセキュリティの基礎(AWS/Azure)](../../modules/02-cloud-security-basics/README.md) | クラウドでよくある設定ミスとその見つけ方 |
| 3 | [インシデント対応の基礎](../../modules/03-incident-response-basics/README.md) | 何かが起きたときの初動・報告の整理方法 |
| 4 | [セキュア設定レビュー](../../modules/04-secure-config-review/README.md) | 設定ファイル・IaCをセキュリティ観点でレビューする方法 |

## 進め方の目安

- 各モジュールは、概念の説明 → ハンズオン(ダミーデータ) → Claudeへの質問例、という構成です
- 1つのモジュールを終えたら、[templates/ja/](../../templates/ja/) の対応するプロンプトを、自分の現場に合わせて試してみてください(本番の機密データは使わないでください)
- すべて終えたら、[tools/log-triage-agent/](../../tools/log-triage-agent/) で自動化の入り口を体験してみてください

## 前提知識

- ネットワーク・サーバー・クラウドの基本的な運用経験(専門家である必要はありません)
- セキュリティの専門知識は前提としません。各モジュール内で必要な概念を説明します
