# Claude セキュリティ道場 (ClaudeSecDojo)

**Claudeを使って、ITエンジニアがセキュリティの実務力を身につけるための初心者向けオープンソースプロジェクト。**
ネットワーク運用・クラウド構築・ログ分析など「現場の実務」を起点に、Claudeを相棒にしてセキュリティの考え方と手順を学べるガイド・プロンプトテンプレート・実動くツールをまとめています。

[English version here](README.en.md)

## これは何か

セキュリティは「専門チームだけの仕事」ではなく、インフラ・クラウド・開発に関わる全エンジニアが日常的に向き合う領域です。しかし多くの現場エンジニアは、

- ログの中から異常をどう見つけるか
- クラウドの設定ミスをどうチェックするか
- インシデントが起きたときに何をどう報告するか

といった実務の進め方を、体系的に学ぶ機会が少ないまま現場に立っています。

このリポジトリは、**攻撃手法の習得ではなく「防御・検知・報告」の実務力**を身につけることを目的に、以下を提供します。

- セキュリティの考え方を学べる**学習モジュール** ([modules/](modules/))
- そのままコピーして使える**プロンプトテンプレート** ([templates/](templates/ja/))
- 実際に動く**簡単なツール**(ログ異常検知の下書き生成など) ([tools/](tools/))

**このリポジトリの範囲:** ログ分析・設定レビュー・インシデント報告など、守る側(ディフェンシブ)の実務支援に限定しています。実在のシステムへの攻撃手法や侵入テスト手法そのものは扱いません。

## 他のセキュリティ学習OSSとの違い

セキュリティを学べるOSSは他にも数多くあります。本リポジトリが意識しているのは、「セキュリティに詳しい人が初心者向けに書いた教材」ではなく、**専門用語を一切前提にしない教材**であることです。

- 専門用語は、出てきたその場で平易な言葉に言い換えます(「あとで用語集を見てください」とは言いません)
- 「わかる人は読み飛ばしてよい、わからない人もそのページだけで理解できる」ことを目指します
- ハンズオンは、架空のダミーデータだけで完結し、特別な環境構築を前提にしません

これは、著者自身がAWS/Azureの企業研修講師として、技術に不慣れな人に説明してきた経験に基づいています。

## クイックスタート

1. [docs/ja/getting-started.md](docs/ja/getting-started.md) を読む
2. [docs/ja/learning-path.md](docs/ja/learning-path.md) で学習の進め方を確認する
3. [modules/](modules/) のモジュールを1つずつ進める
4. 実務でよく使う場面があれば [templates/ja/](templates/ja/) のプロンプトをコピーして使う
5. もう少し自動化したくなったら [tools/log-triage-agent/](tools/log-triage-agent/) のサンプルを動かしてみる

## リポジトリ構成

```
docs/        学習ガイド・学習パス (ja/ と en/)
modules/     セキュリティ学習モジュール(各モジュールは日英バイリンガル1ファイル)
templates/   コピペで使えるプロンプトテンプレート (ja/ と en/)
tools/       実際に動く小さなツール・エージェントのサンプル
```

## 対象読者

- ネットワーク・インフラ・クラウド運用に携わるITエンジニア
- セキュリティ初心者だが、現場でログや設定ファイルに触れる機会がある人
- 社内でセキュリティの基礎を広めたい立場の人(研修講師・リードエンジニアなど)

## 前提とお願い

- 本リポジトリの内容は学習・防御目的です。実在のシステム・他者の環境への無断アクセス・攻撃には使用しないでください
- ハンズオンは、学習用に用意したダミーデータ・ローカル環境を使うことを前提にしています
- 本番環境の機密情報(実際のログ・認証情報・顧客データなど)をそのままClaudeに入力しないでください
