# ClaudeManagement

**A beginner-friendly open-source project for running a business with Claude.**
Guides, prompt templates, and working tools that help executives, managers, and solo founders around the world use Claude (Anthropic's AI model) in day-to-day management work.

[日本語版はこちら](README.md)

## What this is

Executives and managers spend a huge share of their time on language work: decisions, reports, meeting summaries, strategy reviews. Claude can strongly assist with the drafting, organizing, and first-pass thinking behind that work, but many people hit a wall of "I don't know where to start" or "I don't know how to write a good prompt."

This repository assumes **no programming experience** and provides:

- **Guides** for using Claude in management contexts ([docs/](docs/en/))
- **Prompt templates** you can copy and use as-is ([templates/](templates/en/))
- **Simple working tools** such as an automatic weekly-report generator ([tools/](tools/))

## Quick start

1. Read [docs/en/getting-started.md](docs/en/getting-started.md) (what Claude is, where to start)
2. Copy a prompt from [templates/en/](templates/en/) and paste it into [claude.ai](https://claude.ai) or Claude Code
3. When you're ready to automate further, try the example in [tools/weekly-report-agent/](tools/weekly-report-agent/)

## Repository layout

```
docs/        Guides and use cases (ja/ and en/)
templates/   Copy-paste prompt templates (ja/ and en/)
tools/       Small working tools / agent examples
```

## Who this is for

- Executives and managers bringing AI into their business for the first time
- IT/ops staff who want to spread Claude adoption inside their company
- Engineers with little to no prior programming experience
