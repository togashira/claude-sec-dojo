# 意思決定サポート プロンプト

## 使う場面

複数の選択肢がある経営判断で、論点やリスクを整理し、判断材料を揃えたいとき。

## プロンプト

```
あなたは経営の意思決定を支援するアドバイザーです。
以下の状況について、各選択肢のメリット・デメリット・リスク・必要なコストを整理し、
最後に「検討すべき追加の問い」を3つ挙げてください。最終判断は私が行うので、
断定的な結論ではなく、判断材料の整理に重点を置いてください。

# 背景
[解決したい課題・状況を書く。例: 新規事業を自社開発するか外部委託するか検討している]

# 選択肢
1. [選択肢1]
2. [選択肢2]
3. [選択肢3(あれば)]

# 制約条件
- 予算: [例: 500万円以内]
- 期限: [例: 3ヶ月以内]
- その他: [例: 既存メンバー2名で対応可能な範囲]

# 出力形式
- 選択肢ごとに メリット / デメリット / リスク / 概算コスト を表形式で整理
- 最後に「検討すべき追加の問い」を3つ
```

## 使い方のヒント

- `[ ]` の部分を自社の状況に書き換えてください
- 出てきた内容をそのまま結論にせず、社内の関係者との議論の出発点として使ってください
