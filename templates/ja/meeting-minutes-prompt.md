# 議事録・会議メモ整理 プロンプト

## 使う場面

会議中に取った雑多なメモや発言ログを、議事録・決定事項・ToDoリストに整理したいとき。

## プロンプト

```
以下は会議中に取った生のメモです。これを整理して、
1. 会議の概要(3行以内)
2. 決定事項(箇条書き)
3. ToDo(担当者と期限がわかる場合はそれも記載。不明な場合は「担当者未定」と明記)
4. 保留・持ち越しになった論点
の4つに分けて出力してください。メモにない情報は推測で埋めず、「記載なし」としてください。

# 会議の基本情報
- 日時: [例: 2026年11月7日]
- 参加者: [例: 山田, 鈴木, 外部パートナーA社]
- 議題: [例: 新商品の価格戦略について]

# 生のメモ
[ここに会議中のメモ・発言ログを貼り付ける]
```

## 使い方のヒント

- メモが口語的・断片的でも問題ありません。そのまま貼り付けてください
- 「記載なし」とされた項目は、必要に応じて関係者に確認してください
