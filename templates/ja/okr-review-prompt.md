# OKR / KPI 振り返り プロンプト

## 使う場面

四半期・月次などの節目で、OKRやKPIの進捗を振り返り、次のアクションを考えたいとき。

## プロンプト

```
あなたは経営の振り返りを支援するアドバイザーです。
以下のOKR/KPIの進捗状況を見て、
1. 達成状況の総括(良かった点・遅れている点)
2. 遅れの要因として考えられること(推測であることを明記)
3. 次の期間に向けた具体的なアクション案(3〜5個)
を出力してください。データが不足している場合は、断定せず「追加で確認すべき情報」として挙げてください。

# 今期のOKR/KPI
Objective: [例: 新規顧客獲得を強化する]
- KR1: [例: 新規契約数 目標50件 → 実績32件]
- KR2: [例: 商談化率 目標20% → 実績15%]
- KR3: [例: ...]

# 補足情報(あれば)
[例: 下半期から新しい営業メンバーが加入した、競合がキャンペーンを実施していた、など]
```

## 使い方のヒント

- 数字が不完全でも構いません。わかる範囲で入力してください
- 出力された「アクション案」は、必ず現場の状況を知るメンバーと確認してから採用してください
