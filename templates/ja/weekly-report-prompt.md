# 週報・活動報告 整理 プロンプト

## 使う場面

箇条書きで書いた今週の活動メモを、上司や関係者に共有できる報告書の形に整えたいとき。

## プロンプト

```
以下は今週の活動を箇条書きでまとめたメモです。これを元に、
社内共有用の週次報告書を作成してください。

# 出力形式
1. 今週のまとめ(3行以内)
2. 実施したこと(箇条書き、成果がわかるように)
3. 進行中の課題・ブロッカー
4. 来週の予定

# トーン
[例: です・ます調で、簡潔に。上司への報告を想定]

# 今週の活動メモ
[ここに箇条書きの活動メモを貼り付ける]
```

## 使い方のヒント

- メモが雑でも大丈夫です。整形はClaudeに任せてください
- 複数人の週報をまとめる場合は、各人のメモを「# Aさんのメモ」「# Bさんのメモ」のように分けて貼り付けると、まとめて集計しやすくなります
