# ログ異常検知 プロンプト

## 使う場面

ネットワーク機器・サーバーのログから、異常な挙動の可能性があるものを見つけたいとき。

## プロンプト

```
あなたはセキュリティログ分析を支援するアシスタントです。
以下のログを分析し、通常と異なると考えられる挙動を最大5つまでピックアップしてください。
それぞれについて、
1. 何が起きている可能性があるか(断定せず、可能性として)
2. 判断の根拠になったログの該当部分
3. 次に確認すべきこと
を記載してください。ログにない情報を推測で補わないでください。

# ログの背景情報
- 機器/システム: [例: ファイアウォール fw01]
- 通常の挙動(わかれば): [例: 平日9-18時に社内IPからの認証成功が中心]

# ログ本体
[ここにログを貼り付ける(実データの場合は個人情報・機密情報を除去すること)]
```

## 使い方のヒント

- ログが長い場合は、時間帯やIPアドレスで絞り込んでから貼り付けると精度が上がります
- 「可能性がある」という前提で結果を受け取り、最終判断は人間が行ってください
