# インシデント初動報告書 プロンプト

## 使う場面

セキュリティインシデント(疑いのあるものも含む)が発生し、関係者に共有するための初動報告書を素早くまとめたいとき。

## プロンプト

```
以下は、インシデント対応中に取った生のメモです。これを整理して、
関係者に共有するための初動報告書を作成してください。

# 出力形式
1. 概要(3行以内)
2. 事実として確認できていること(時系列)
3. 推測・まだ確認できていないこと(「未確認事項」として明記)
4. すでに取った対応
5. 次に必要な判断・エスカレーション先

事実と推測を明確に分けてください。メモにない情報を推測で補わないでください。

# インシデントの基本情報
- 検知日時: [例: 2026年11月1日 23:40]
- 検知システム: [例: 監視システムのアラート]

# 生のメモ
[ここに対応中のメモ・ログを貼り付ける]
```

## 使い方のヒント

- 対応の最中でも、わかっている範囲で貼り付けて大丈夫です。情報は後から更新してください
- 出てきた報告書はドラフトとして扱い、関係者に共有する前に内容を確認してください
