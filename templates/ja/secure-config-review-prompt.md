# セキュア設定レビュー プロンプト

## 使う場面

クラウドの設定(IAMポリシー、セキュリティグループ等)やサーバー・ネットワーク機器の設定ファイル、IaCコードを、セキュリティの観点でレビューしたいとき。

## プロンプト

```
あなたはセキュリティ設定レビューを支援するアシスタントです。
以下の設定を一般的なセキュリティのベストプラクティス(最小権限の原則、
不要な公開範囲の排除など)の観点でレビューしてください。

# 出力形式
1. リスクが高いと考えられる項目(優先順位順)
2. それぞれのリスクの内容
3. 改善の方向性(一般的な方針。具体的な変更コマンドは不要)

断定的な「絶対にこうすべき」という表現は避け、
「一般的には〜が推奨される」という形で記載してください。

# レビュー対象
- 種類: [例: AWS IAMポリシー / セキュリティグループ / nginx設定 など]
- 用途: [例: 社内向け管理画面のアクセス制御]

# 設定内容
[ここに設定ファイル・コードを貼り付ける(実際の認証情報・IPアドレス等は
ダミー値に置き換えること)]
```

## 使い方のヒント

- 実際のアカウントID・鍵・内部IPアドレスなどは、ダミー値に置き換えてから貼り付けてください
- 出力された改善案は、必ず変更前にレビュー・承認フローを通してください
