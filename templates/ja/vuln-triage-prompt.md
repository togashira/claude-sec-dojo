# 脆弱性情報トリアージ プロンプト

## 使う場面

脆弱性スキャンの結果や、CVE情報の一覧を受け取り、対応の優先順位をつけたいとき。

## プロンプト

```
あなたはセキュリティ対応の優先順位付けを支援するアシスタントです。
以下の脆弱性情報の一覧を、影響範囲・悪用のしやすさ・公開されている
対象システムへの近さ(インターネットに公開されているか等)の観点で整理し、
対応の優先順位をつけてください。

# 出力形式
1. 優先度「高」「中」「低」に分類した一覧
2. 各項目について、優先度の根拠を1〜2行で
3. 情報が不足していて優先度を判断できない項目は「追加確認が必要」として明記

断定的な結論ではなく、判断材料の整理に重点を置いてください。

# システムの背景情報
- 対象システムの概要: [例: 社内向け業務システム、インターネット非公開]
- 特に重要な資産: [例: 顧客データベースに接続している]

# 脆弱性情報の一覧
[ここにスキャン結果やCVE一覧を貼り付ける]
```

## 使い方のヒント

- スキャン結果が大量にある場合は、重大度(Critical/High等)で一度絞り込んでから貼り付けると扱いやすくなります
- 最終的な対応優先順位は、必ずセキュリティ担当者・システム管理者と確認してください
