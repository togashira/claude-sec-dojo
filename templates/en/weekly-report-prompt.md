# Weekly Report Prompt

## When to use it

You have a bullet-point list of this week's activities and want it turned into a report you can share.

## Prompt

```
Below are bullet-point notes on this week's activities. Turn them into a weekly
status report for internal sharing.

# Output format
1. This week's summary (3 lines or fewer)
2. What was done (bullet list, with outcomes where possible)
3. Ongoing issues / blockers
4. Plan for next week

# Tone
[e.g. concise and professional, written for a manager]

# This week's notes
[Paste your bullet-point notes here]
```

## Usage tips

- Messy notes are fine - let Claude do the formatting
- To roll up several people's reports, paste each person's notes under its own heading (e.g. "# Jane's notes", "# Mike's notes") so Claude can summarize them together
